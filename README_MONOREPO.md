Monorepo Wallet Voice App

Frontend: frontend/
Backend: backend/

Instrucciones rapidas
- Instalar y correr frontend: cd frontend; npm install; npm start
- Instalar y correr backend: cd backend; npm install; npm start

Notas
- Esta estructura te permitirá desplegar cada componente de forma independiente.
- Para automatizar migraciones, usa los scripts en scripts/move_monorepo.*.
